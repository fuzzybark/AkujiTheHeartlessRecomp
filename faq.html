Frequently Asked Questions & Legal

Answers to common questions regarding compatibility, static recompilation, system requirements, and legal compliance.

1. General Questions

What is a "Static Recompilation"?

Unlike traditional emulators that interpret or just-in-time compile PlayStation machine code instruction-by-instruction at runtime, a static recompiler translates the entire original MIPS binary ahead of time into native C code. This C code is then compiled directly into a native Windows executable with an optimizing compiler (such as Clang). The result is negligible CPU overhead, zero micro-stutter, and direct access to native PC enhancements.

Is this an emulator?

No. It is a compiled native Windows application that links the recompiled game code against a lightweight runtime framework (psxrecomp) that simulates PS1 hardware peripherals (GPU rasterizer, SPU audio synthesizer, CD-ROM controller, and DMA channels) directly on modern APIs like OpenGL and SDL3.

Does this include the game?

No. The release package contains only the recompiled executable engine and open-source runtime components. It contains zero copyrighted level data, textures, models, dialogue, or music. You must supply your own authentic disc dump.

Why is OpenBIOS used instead of retail BIOS?

Retail PlayStation BIOS ROMs (e.g., SCPH-1001) are proprietary, copyrighted software owned by Sony Interactive Entertainment. Redistributing a retail BIOS is illegal. Akuji Recomp ships with OpenBIOS, a 100% clean-room, open-source reverse-engineered implementation of the PS1 kernel released under the MIT license, allowing the software to boot out-of-the-box legally.
