Technical Overview

Engine Features & Enhancements

A breakdown of the graphics enhancements, input features, and quality-of-life additions available in the standalone recompilation.

1. Graphics Presets

The launcher provides two one-click configuration baselines:

Setting Original PS1 Preset Enhanced PC Preset
Internal Resolution Native 240p (1x) 1080p / 1440p / 4K
Texture Filtering Nearest (Raw pixel art) Bilinear Smoothing
PGXP Sub-Pixel Precision Disabled (Authentic polygon wobble) Enabled (Stable vertices)
Perspective Texturing Disabled (Affine PS1 warping) Enabled (Perspective-correct)
Aspect Ratio Original 4:3 (Pillared) Original 4:3 / Stretch

2. Presentation Decoupling (30 Hz to 240 Hz)

PlayStation 1 titles typically bind game simulation and physics to the fixed 30 Hz NTSC vertical sync. Rather than artificially speeding up game mechanics, Akuji Recomp utilizes presentation decoupling:

  • 30 FPS (Original PS1): Authentic native game cadence with zero frame interpolation.
  • 60 / 120 / 144 / 200 / 240 FPS: Generates smooth intermediate presentation frames without altering game speed, physics gravity, or jump timing.
  • Match Display Refresh: Automatically synchronizes the frame presentation rate with your high-refresh gaming monitor (e.g., 144 Hz, 165 Hz, 240 Hz).

3. Supersampling Anti-Aliasing (SSAA)

In addition to arbitrary internal resolutions, Akuji Recomp provides internal supersampling:

  • Off (1x): Standard native buffer output.
  • 2x, 3x, 4x SSAA: Renders geometry and rasterization at up to 4× your target internal resolution, downsampling for razor-sharp polygon edges without blurring textures.

4. In-Game Keyboard & Controller Shortcuts

Instant real-time toggles are mapped directly to hotkeys for on-the-fly adjustment:

Key Action Effect
Alt + Enter Fullscreen Toggle Switches between Windowed and Borderless Fullscreen
F1 Quicksave Saves an instantaneous state snapshot to Slot 1
F3 Quickload Instantly restores the snapshot from Slot 1
F5 Cycle Resolution Cycles Native → 720p → 1080p → 1440p → 4K
7 Toggle PGXP Toggles sub-pixel vertex precision
8 Perspective Texturing Toggles perspective-correct UV interpolation
9 Texture Filtering Toggles Bilinear smoothing vs Nearest pixelation
F11 CRT Scanline Filter Toggles retro CRT scanline simulation
Backspace Rewind (Hold) Rewinds active gameplay up to 10 seconds in real time
Tab Fast Forward (Hold) Accelerates cutscenes and dialogue

5. Memory Card Preservation

Your progression is stored in authentic PlayStation Memory Card format at saves/card1.mcd and saves/card2.mcd. In-game sanctuary save shrines write standard save blocks that can be read, backed up, and exported using standard memory card utilities like MemcardRex.
