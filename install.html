Installation & Game Files Guide

Follow these steps to extract the release archive, provide your legally owned PS1 disc image, and start playing.

Legal Requirement: User-Provided Disc

Akuji the Heartless Recomp does not include any copyrighted game software, level geometry, textures, audio tracks, or retail BIOS files. You must provide a disc image dumped from your own authentic retail copy of Akuji the Heartless (USA).

Step 1: Download the Release Archive

Download the latest Windows binary release package (akuji-recomp-v0.1.0-windows-x64.zip) from the official GitHub Releases page. Extract the contents of the ZIP archive into a dedicated folder on your computer (e.g., C:\Games\AkujiRecomp\).

Step 2: Obtain Your Disc Image

The recompilation requires the NTSC-U (USA) release of the game:

  • Title: Akuji the Heartless
  • Product Code: SLUS-00715
  • Format: Standard .cue / .bin image (Redump compatible).

How to Dump Your Retail CD-ROM

  1. Insert your original disc into your PC's optical CD/DVD drive.
  2. Use optical ripping software such as ImgBurn (Read mode) or AnyBurn.
  3. Save in BIN/CUE format: Ensure the software creates a .cue sheet alongside the track .bin files so CD-DA audio tracks are preserved.
  4. Verify track filenames: A standard dump contains:
    • Akuji the Heartless (USA).cue
    • Akuji the Heartless (USA) (Track 1).bin (Data)
    • Akuji the Heartless (USA) (Track 2).bin (Audio)
    • Akuji the Heartless (USA) (Track 3).bin (Audio)

Step 3: Placing the Disc Files

Place your .cue and .bin files directly inside the disc/ subfolder inside the extracted game directory: 

AkujiRecomp/
├── AkujiTheHeartless_Recompiled.exe   # Main game executable
├── game.toml                         # Engine configuration
├── game_options.toml                 # Quality presets
├── keybinds.ini                      # Input bindings
├── bios/
│   ├── openbios.bin                  # Clean-room open-source BIOS (MIT)
│   └── OpenBIOS.LICENSE
├── disc/
│   ├── Akuji the Heartless (USA).cue
│   ├── Akuji the Heartless (USA) (Track 1).bin
│   ├── Akuji the Heartless (USA) (Track 2).bin
│   └── Akuji the Heartless (USA) (Track 3).bin
└── saves/                            # Memory cards generated on first save

Tip: Selecting via Launcher

Alternatively, you can place your disc image anywhere on your drive. When launching AkujiTheHeartless_Recompiled.exe, the launcher's Game tab allows you to browse and select any valid .cue file on your computer.

Step 4: Launching the Game

Double-click AkujiTheHeartless_Recompiled.exe to open the Recomp Launcher:

  1. Verify your disc is detected under the Game tab.
  2. Select your preferred graphics preset (Original PS1 or Enhanced PC) under the Graphics tab.
  3. Set your target refresh rate (e.g., 60 FPS, 144 FPS, or Match Display Refresh).
  4. Click Launch to start the game!

Troubleshooting & FAQ

  • Error: "No disc found": Ensure your .cue file is located in the disc/ directory or selected via the launcher. Verify that the filenames referenced inside the .cue file match the exact filenames of your .bin files.
  • Music is silent: Ensure your disc was dumped as a multi-track image with audio tracks. Single-track ISO rips do not include the redbook audio tracks used for background music.
  • Missing DLL errors: Ensure you have installed the latest Microsoft Visual C++ Redistributable (x64).
