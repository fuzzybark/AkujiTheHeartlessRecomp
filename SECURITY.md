# Security Policy

## Supported Versions

Security updates and critical stability fixes are applied to the latest release of **Akuji the Heartless Recomp**:

| Version | Supported |
|---|---|
| Latest Release (v0.1.0+) | :white_check_mark: |
| Older Versions / Historical Checkpoints | :x: |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit (such as memory corruption in disc parsers, buffer overflows in file loaders, or unsafe memory execution in the recompiled runtime):

1. **Do not create a public issue.** Please do not disclose vulnerabilities in public issue trackers or discussion boards until they have been reviewed and mitigated.
2. **Submit a Private Report:** Send details of the vulnerability to the project maintainers via GitHub's Private Vulnerability Reporting feature (under the repository's **Security** tab).
3. **Include Reproduction Steps:** Provide a clear description of the issue, affected components, proof-of-concept steps or inputs, and potential impact.
4. **Response Timeline:** We aim to acknowledge reports within 48 hours and provide remediation or mitigation timelines shortly thereafter.
